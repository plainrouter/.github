# Plainrouter

Plainrouter is a hosted Meta Ads MCP server and API for developers and AI agents. Read Meta ad account context and conversion-signal health, then propose pauses, resumes, budget changes and creative tests. In Ask mode, a person approves each change; Full mode can queue policy-allowed changes automatically.

Plainrouter also tracks first-party conversion events and keeps its own counts of website arrivals and verified revenue beside Meta’s reporting.

To use your own ad account, sign up on the website and connect Meta before configuring an SDK, CLI or agent.
